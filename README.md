# Trabalho de Conclusão de Curso (TCC)
## A Expansão dos Data Centers de Big Techs no Brasil: Impactos Socioambientais e Dinâmicas de Colonialismo Digital

Repositório oficial do Trabalho de Conclusão de Curso apresentado ao curso de **Sistemas de Informação da Faculdade Multivix**. 

Este repositório foi estruturado sob os princípios de **pesquisa reprodutível** e ciência aberta, permitindo a rastreabilidade completa entre o texto final, as fontes bibliográficas utilizadas e as notas de análise documental.
