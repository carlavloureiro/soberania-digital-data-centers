# Referências Bibliográficas (Acervo Documental)

Esta pasta armazena o acervo bibliográfico e documental utilizado como fundamentação teórica e empírica para a elaboração do Trabalho de Conclusão de Curso (TCC).

Em alinhamento com as diretrizes de **pesquisa reprodutível** e ciência aberta, este diretório reúne as fontes acadêmicas internacionais e nacionais que sustentam a análise sobre soberania digital, colonialismo de dados e infraestrutura governamental.
